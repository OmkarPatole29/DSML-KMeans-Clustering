# K-Means Clustering on Digits Dataset

## Description

This project implements the K-Means clustering algorithm on the Digits dataset using Python to group similar handwritten digit images.

## Experiments

- **Data Loading:** Loads the Digits dataset using Scikit-learn.
- **Data Preprocessing:** Standardizes the dataset features.
- **K-Means Clustering:** Groups digit images into 10 clusters.
- **Performance Analysis:** Evaluates clustering using inertia and silhouette score.
- **Visualization:** Uses PCA and scatter plots to visualize the clusters.

## Technologies Used

- Python
- NumPy
- Matplotlib
- Scikit-learn
- Jupyter Notebook

## Dataset

Built-in Digits dataset from Scikit-learn.

## How to Run

1. Install the required libraries using `pip install numpy matplotlib scikit-learn`.
2. Open the notebook in Jupyter Notebook.
3. Run each cell in order.
4. Observe the clustering results and visualizations.

## Objective

To understand and implement K-Means clustering and analyze the grouping of handwritten digit images using visualization techniques.
